# Source and resource provenance

The UI HTML and embedded images were supplied in the user's Stitch export. Fonts and icons referenced by that export were downloaded from Google Fonts, with the original CSS preserved. The Tailwind CSS browser runtime was copied from the versioned official CDN endpoint https://cdn.tailwindcss.com/3.4.17.

The Android Gradle wrapper files were obtained from https://github.com/gradle/gradle/tree/v8.9.0. They are unmodified.

No license is newly assigned to user-provided designs or third-party resources. This bundle is a project prototype; attribution and distribution rights should follow the original resources.
